## But

**Le placement.** Un point est projeté par `projeter_epsg3035` et placé dans **la** cellule du monde dont le polygone (`monde.carte[cell_id]["geometry"]`) le contient, par `point_dans_geometrie` de `sim/villes.py` : aucun polygone, il est hors carte ; deux polygones, le test échoue en nommant le point. Jamais de centroïde le plus proche.

**La preuve** est une fonction du test, `epreuve(monde, vue)`, qui rend la liste de ses échecs (vide : la preuve tient) :
1. densité d'une région = somme des `population` / somme des `area_km2` de ses cellules distinctes ; médiane = médiane de `population / area_km2` sur toutes les cellules du monde ; chaque région dense est **strictement** au-dessus, le désert **strictement** au-dessous ; une région sans aucune cellule placée échoue ;
2. les quatre points connus placés sont à leur puissance ; Venise est hors carte comme déclaré ;
3. chaque point déclaré hors carte l'est vraiment, et chaque point non déclaré tombe dans une cellule couverte, sinon échec nommé ; parmi les points couverts, au moins ⌈2 × couverts / 3⌉ sont justes, couverts et seuil dérivés des données, un échantillon vide échoue.

## Conditions de succès
- **SC1 — la preuve tient sur le monde amorcé.** `cd jeu && python3 -m pytest sim/tests/test_epreuve_jalon2.py -q -s -k tient` : `epreuve(World.charger(0), puissances_depuis_monde(monde))` rend une liste vide ; le test imprime la médiane, la densité et les cellules de chaque région, la cellule et la puissance de chaque point, le compte « justes / couverts / seuil » (35 / 51 / 34 attendus), et chaque point déclaré avec sa raison. Contre-épreuve : SC2 et SC3.
- **SC2 — sans aridité, la preuve échoue.** `cd jeu && python3 -m pytest sim/tests/test_epreuve_jalon2.py -q -k sans_aridite` : avec `monkeypatch.setattr(constants, "facteur_eau", lambda pluie: 1.0)` avant `World.charger(0)`, `epreuve` rend au moins un échec, et un échec nomme le désert occidental. Le test vérifie aussi que le monde sans aridité diffère bien du monde témoin (densité du désert différente), pour qu'un `monkeypatch` sans effet ne passe pas pour une contre-épreuve.
- **SC3 — frontières mélangées, la preuve échoue.** `cd jeu && python3 -m pytest sim/tests/test_epreuve_jalon2.py -q -k melangees` : la vue permutée comme dit plus haut fait rendre à `epreuve` un échec sur le seuil des deux tiers ; le test imprime le compte obtenu. Le test vérifie que la permutation a changé au moins une cellule.
- **SC4 — la table se refuse quand elle ment.** `cd jeu && python3 -m pytest sim/tests/test_epreuve_jalon2.py -q -k table` : la table réelle a 5 points connus, 4 régions denses, 1 région vide, 53 points, 1 déclaré ; chaque ligne a une `source` non vide ; chaque attente est le nom d'une puissance de `data/puissances-1400.json` ; aucun des 53 points ne porte le nom d'une ancre de cette table. Contre-épreuves sur des copies modifiées en mémoire : une source vide, une attente inconnue (« Bourgogne »), Stockholm sans sa déclaration (hors carte non déclaré), Venise privée de sa déclaration, chacune fait échouer la lecture ou `epreuve` en nommant le point.
- **SC5 — aucun module du moteur ne lit la table.** `cd jeu && python3 -m pytest sim/tests/test_epreuve_jalon2.py -q -k aucun_module` : aucun fichier `.py` de `sim/` hors de `sim/tests/` ne contient `reference-jalon2`.
