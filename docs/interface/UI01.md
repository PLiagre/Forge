# UI-01 — thème, composants et galerie

État : réalisé et vérifié, PR à ouvrir ; pas encore livré dans le jeu. Code éprouvé : `9d9429bbe55ef32d3bdb2ac2345426187478f437`.
Le joueur gagne le socle de lecture : papier clair sur cadre sombre, deux dossiers simultanés, commandes actives/inactives et focus avec contour. Aucune connexion au monde ni quantité de jeu inventée.
Dans Unity 6000.0.43f1 : menu **Forge → Interface → Galerie du socle** ; après proposition de sauvegarder la scène courante, une scène isolée démarre en Play. Flèches/Entrée ou souris ; arrêter Play pour revenir à l’éditeur.
Preuve du 15 octobre 2026 : cinq tests échouent sur le socle vide, puis les six tests finaux passent, dont le démarrage en Play, le clic, le focus et le refus d’action inactive. Aucun test existant modifié.
Exécution isolée avec les versions de paquets du dépôt : copier `Assets/Interface` dans un projet Unity et utiliser le manifeste de l’archive ; `Unity.exe -batchmode -nographics -projectPath <projet> -runTests -testPlatform EditMode -testFilter Forge.Interface.Tests -testResults <resultats.xml>`.
[Résultats bruts rouge/vert et manifeste](preuves/UI01-9d9429b.zip) ; [capture réelle en Play](preuves/UI01-9d9429b.png), prise sur le même code, regardée : aucun texte coupé à 1920 × 1080, deux dossiers présents, focus distinguable.
Comparaison aux références : papier/encre de `imprimerie_1600.png`, accents chauds limités de `forge_1450.png` ; le socle reste volontairement sans illustration de monde et sans fausse identité historique.
Limites déclarées : police Unity provisoire, sans texture ni portrait ; preuve dans un projet de contrôle isolé, pas de validation du parcours complet du jeu. La galerie est générée par le menu, sans scène sérialisée ajoutée au dépôt.
