# Matières du cabinet

Les 108 références sont regardées sur les douze planches : bois et lin du
conseil, papier de l’imprimerie, accents de la forge, bleus et verts grisés des
territoires. Les cadres gardent un filet fin.

Les panneaux communs reçoivent un papier légèrement grainé, une tranche sombre
et une ombre courte. Le bandeau est sombre ; les commandes ordinaires sont
brunes, le focus bleu, les confirmations portent une cire rouge. Les matières
sont générées une fois, sans utiliser l’aléa de la simulation. Aucun nombre ni
parcours de décision ne change.
