# Victoria City Mode Assets

Portable, presentation-only content for ForgeHistory City Mode. Content is
partitioned into `Common`, `Biome` and `City`; the host loads those partitions
explicitly and releases them in reverse order. This package contains no world
identity, simulation, clock, save, fixture or `Resources.Load` path.

The authoritative source-to-target hashes, GUIDs, provenance and licences live
in `Docs/Integration/city-mode-asset-port-v1.json`.
