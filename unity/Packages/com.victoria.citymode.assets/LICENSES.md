# Content licences

- `common/*` and `biome/*`: original Victoria CityLab procedural artwork,
  licensed for use by the Victoria projects (`LicenseRef-Victoria-Original`).
- `city/*`: procedural adaptations generated from the EmaceArt *Slavic World
  Free* Unity Asset Store pack. The source and adapted files remain subject to
  the Unity Asset Store EULA and may only be distributed in the private project
  as embedded game content (`LicenseRef-Unity-Asset-Store-EULA`).

The package never republishes the immutable Vendor source hierarchy. Exact
source files, recipes and hashes are recorded in the port manifest and the
repository Vendor audit.
